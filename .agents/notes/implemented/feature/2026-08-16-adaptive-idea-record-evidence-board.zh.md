# Agent Note：把自适应 Idea Record 投影到每次科研请求

Status: implemented

[English](2026-08-16-adaptive-idea-record-evidence-board.md) | 中文

## Problem

长时间运行的科研 Agent 需要维持持久的科学连续性，但不能把全部研究历史或僵硬、不断膨胀的框架塞进每次模型请求。固定提示词可能保住文字，却仍会过度约束探究；完整论证图即使大部分与当前动作无关，也会持续消耗注意力。如果每个暂定想法和普通实验都成为审批门，人类监督也会退化成低效的任务调度。

## Decision

**Pi-Idea 在模型外保存自适应 Idea Record，并为每次请求投影一个窄的 Idea Lens。** 用户确认的 Idea Seed 被重新定义为“研究追求”慢变量：每个已确认版本不覆写，但当反馈暴露出更值得追逐的科学对象、成功含义或边界时，当前有效版本可以经模型提案和人类一次确认后澄清、调整或转向。有界 Inquiry Map 保存带类型的问题、假设、竞争解释、证据、反证、决定和否决原因。一个 Decision Frontier 指出当前期望决策价值最高的问题。上下文组装器针对执行、探索、审计或论文任务，最多选择五个相关且对模型可见的节点及必要的一跳关系；完整 Map 永远不会成为常驻提示词 section。

状态按四个时间尺度演化：Working State 快改，Inquiry Map／Decision Frontier 跟随活跃未知，Research Frame 在路线或瓶颈改变时中速调整，研究追求只慢改。没有固定冷却期或多重审批；系统先问“最低哪一层已经足以吸收这份反馈”。慢变量提案必须记录 `clarify`／`adjust`／`pivot` 之一，并附带“哪个反馈使旧版本不足 + 哪些承诺仍保留”。这使用户可以边做边明白自己真正想追逐什么，而不必在开始时就假装已经知道终局。

科学证据推进优先于泛化的安全顾虑。安全只是动作准入检查，不是与科研竞争的目标。新数据只有在改变活跃假设或竞争解释、Decision Frontier、论文证据义务或共享路线诊断时，才最多触发一次有界复盘。当证据支持时，模型可以在既有 Seed 内自主提出并验证暂定新想法。只有改变科学对象、成功标准或禁止偷换项的提案，才成为由人负责的 leap。待决 leap 只阻塞它命名的动作，独立证据工作继续推进。当没有正信息价值动作时，Agent 停靠并记录缺少什么证据。

自主性不意味着可以用脑补细节填满证据缺口。控制器和按需 Skill 要求：未说明的机制、领域事实或消融臂必须保留为显式缺失判别量。用户只要一个下一动作时，模型只选择一个最高价值干预；同一干预内可以打包多项测量，但不能把多个替代干预改名成一个动作。

Web 客户端把同一状态呈现为紧凑研究控制台和侧边栏侦探证据板。证据板预先呈现 AI 与人类卡片以及语义连线。拖动卡片只写入工作区级本地布局，绝不会改变 revision、上下文 Manifest 或模型 token。创建或编辑卡片、添加关系、显式改变模型可见性，则通过 research command service 写成追加式语义状态。人类新增内容默认私有。

## Verification

领域测试覆盖按任务投影 Lens、隐藏卡片排除、有界当前 Map 与原始事件保留、非阻塞 leap、不可变人类决定以及白板内容先私有后共享。客户端测试覆盖控制台渲染、leap 裁决、Cordis slot 注册与卸载、语义命令发出，并验证关键不变量：拖动只更新 local storage，不会发出任何 research command。Host、client TypeScript project build 与生产 Web build 均已通过。真实浏览器验收创建、共享、拖动、重载并连接了卡片。五个 DeepSeek V4 Flash High 场景在一个论文场景暴露“脑补消融细节”并修正后全部通过。

最终验收另建 `dsh-self-bootstrap-acceptance` Workspace 与新主对话。DeepSeek 在同一 Session 中确认 Pursuit／Frame v2、修改真实源码、使两处 `toReversed()` 全数组克隆降为 0、直跑聚焦测试 29/29 通过并回写 `keep`。生产构建和 DSH 重启后，同一 Session 与慢变量版本恢复；空 `next_action` 使 UI 正确显示“已停靠”。实战同时发现并修复了“第二个待决权威提案静默覆盖第一个”和“后端拒绝合法空 next action”两个合同错误；对应服务端与 Idea Dock 回归测试合计 32/32 通过。

## Alternatives considered

**每次请求注入完整 Inquiry Map。** 否决：它会把 token 和注意力花在休眠分支上，并在结构化格式内重造长上下文退化。

**用滚动模型摘要替代 Map。** 否决：摘要只适合在压力下作为降级手段；它不是可追溯权威源，并可能静默抹掉竞争解释或负证据。

**每个新假设或实验都要求审批。** 否决：这会把研究者变成调度员，并阻止 AI 自主产出证据。人类权威只保留给慢变量后继版本、改变含义的 leap 与主动介入。

**把初始 Idea Seed 永久冻结。** 否决：它可以防止局部任务偷换目标，却会把早期不完整理解固化成长期偏见。保留历史版本和人类确认边界，已经能防止静默漂移；不需要禁止有证据的演化。

**让白板布局影响检索权重。** 否决：视觉整理服务于人的认知。只有显式语义边、节点内容、状态和可见性可以影响模型上下文。

## Consequences

科研连续性被持久保存，而每次请求只得到当前决策所需的证据。模型可以穿过普通不确定性继续工作，提出受证据约束的改进，并在没有信息性动作时诚实停靠。用户既可在任何时候介入，也可以用反馈逐步修正自己真正的研究追求，而不被早期用词锁死。当前 Map 大小有界，追加式 Session 事件则保留之后重建和审计所需的来源。
